# Guided Customization Flow — Take the Time

## Purpose

The customization flow should feel more like a guided writing desk than a complicated design tool.

The experience should help customers express themselves without feeling overwhelmed.

---

# Step 1 — Who Is This For?

Fields:

- Recipient name
- Occasion
- Relationship
- Delivery timing

Prompt:

> Who are you thinking about as you write this?

Design notes:

- Minimal fields
- Large readable typography
- Calm spacing

---

# Step 2 — Write Your Message

Fields:

- Main message
- Closing line
- Sender name

Reflection prompts:

- What are you thankful for?
- What moment do you want them to remember?
- What would make this feel personal?

Optional help buttons:

- Help me shape this message
- Keep my words exactly as written

Guardrails:

- Preserve the user's authentic voice
- Avoid robotic suggestions

---

# Step 3 — Personalize the Design

Options:

- Approved text zones
- Optional photo upload
- Envelope style
- Color choices if supported
- Printed or hand-finished options

Rules:

- Core artwork stays locked
- Layout structure cannot be broken
- Preserve print-safe formatting

---

# Step 4 — Review Your Proof

Preview includes:

- Card front
- Inside message
- Envelope preview if applicable

Checklist:

- Names are correct
- Message is final
- Shipping information is accurate
- Customer understands proof approval process

Buttons:

- Request Artist Review
- Continue to Order

---

# Artist Review Upsell

Headline:

> Would you like a thoughtful second look?

Copy:

> The artist can review wording, layout, tone, and final presentation before production.

Options:

- No review needed
- Add artist review
- Book a guided session instead

Tone:

- Supportive
- Calm
- Helpful
- Never pushy
