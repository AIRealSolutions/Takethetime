# Card Detail Page Wireframe — Take the Time

## Goal

Help the customer understand the design, emotional purpose, customization options, and production workflow before starting personalization.

---

# Layout

## Left Side

Display:

- Large card preview
- Alternate preview angles
- Inside preview if applicable
- Envelope preview if available

Optional future features:

- Handwritten preview
- Wax seal preview
- Paper texture preview

---

## Right Side

### Card Information

- Card title
- Occasion tags
- Collection name
- Artist note
- Size/orientation
- Paper options
- Estimated production timeline

### Production Options

- Printed text
- Hand-finished details
- Artist review
- Pickup or shipping

### CTA Buttons

Primary:

- Personalize This Card

Secondary:

- Ask for Artist Help

---

# About This Design

Section should explain:

- inspiration behind the artwork
- emotional tone
- best use cases
- recommended occasions

This section strengthens the artist connection.

---

# Suggested Pairings

Show related designs:

- Similar tone
- Matching collection
- Complementary envelopes
- Seasonal recommendations

---

# Customer Confidence Section

Checklist:

- Proof approval included
- Secure checkout
- Production timeline explained
- Pickup and shipping available
- Personal messages kept private

---

# Bottom CTA

Headline:

> Ready to make this personal?

Buttons:

- Start Personalizing
- Book a Guided Session
